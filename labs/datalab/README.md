这是我完成的第一个 CS:APP 实验，主要练习位运算、补码和浮点数表示。

## 代码

我的实现在 [bits.c](./bits.c) 中。

主要实现由我完成，复查时借助 AI 修正了两处边界问题，
并整理了注释和变量名。

## 测试结果

- dlc 编码规则检查通过。
- 所有函数的运算次数均在限制内。
- 本地 btest 测试结果为 36/36。
- 补充检查了整数比较溢出和浮点数乘 2 上溢的边界情况。

## 如何测试

从 [CS:APP 官方实验页面](https://csapp.cs.cmu.edu/3e/labs.html)
下载 Data Lab 的 Self-Study Handout。

解压后，用本目录中的 bits.c 替换实验包中的同名文件，
在实验目录中执行：

```bash
./dlc -e bits.c
make btest
./btest
```

官方 Makefile 使用 -m32，需要支持 32 位编译的环境。

## 复盘

- 根据 y-x 的符号比较大小时，需要考虑异号相减溢出。
- 浮点数乘 2 上溢到无穷大时，需要清零尾数。
- 常规测试通过，也需要检查容易遗漏的边界情况。
